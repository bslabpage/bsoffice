연동 확인 중...

외부에서 접속한 사용자의 구글 로그인 및 승인 요청을 내 구글 시트로 실시간 수신하고 대시보드에서 즉시 승인합니다.

* 배포된 웹 앱 URL을 입력하면 외부 사용자의 승인 요청이 실시간으로 관리자 화면에 즉시 동기화됩니다.

⚡ 2분 만에 끝나는 Google 스프레드시트 무료 클라우드 DB 연동 가이드
  1. 구글 드라이브에서 sheets.new(새 스프레드시트)를 열고 상단 메뉴 [확장 프로그램] ➔ [Apps Script]를 클릭합니다.
  2. 기존 코드를 지우고 우측 상단의 [📋 Apps Script 코드 전체 복사] 버튼을 눌러 붙여넣기 한 뒤 저장(Ctrl+S)합니다.
  3. 우측 상단 [배포] ➔ [새 배포] 클릭 ➔ 유형: 웹 앱(Web App) 선택 ➔ 다음 사용자 권한으로 실행: '나(bosung3116@gmail.com)', 액세스 권한: '모든 사용자(Anyone)'로 설정 후 배포합니다.
  4. 생성된 웹 앱 URL(https://script.google.com/macros/s/.../exec)을 위 입력창에 붙여넣고 [저장]을 누르면 완료됩니다!
