# BOS'S Office - 스마트 통합 비즈니스 오피스 플랫폼

하위 5개 오피스 웹 애플리케이션을 통합 관리하고, Google 계정 인증 및 관리자 승인 시스템, 프로그램별 사용량/사용 인원 통계를 제공하는 상위 통합 오피스 웹 포털입니다.  
**GitHub Pages (정적 웹 호스팅)에 바로 배포하여 `server.py` 백엔드 서버 없이 브라우저만으로 100% 동작하도록 구축되었습니다.**

## 🚀 GitHub Pages 배포 방법

BSoffice는 추가 빌드 과정(npm, webpack 등)이 전혀 필요하지 않은 순수 웹 프로젝트입니다.

### 1단계: GitHub 저장소에 푸시
```bash
git init
git add .
git commit -m "Deploy BSoffice to GitHub Pages"
git branch -M main
git remote add origin https://github.com/<사용자ID>/<저장소이름>.git
git push -u origin main
```

### 2단계: GitHub Pages 활성화
1. GitHub 저장소 페이지의 **Settings** 탭으로 이동합니다.
2. 좌측 메뉴에서 **Pages**를 클릭합니다.
3. **Build and deployment** 항목의 **Source**를 `Deploy from a branch`로 설정합니다.
4. **Branch**를 `main`, 폴더를 `/ (root)`로 선택하고 **Save**를 누릅니다.
5. 1~2분 후 상단에 생성된 배포 URL(`https://<사용자ID>.github.io/<저장소이름>/`)로 접속합니다.

### 3단계: Google Cloud Console 도메인 등록 (Google 로그인 사용 시)
1. [Google Cloud Console](https://console.cloud.google.com/) 접속 -> **API 및 서비스** -> **사용자 인증 정보**
2. 사용 중인 OAuth 2.0 클라이언트 ID 선택
3. **승인된 자바스크립트 원본 (Authorized JavaScript origins)**에 다음 주소를 추가하고 저장합니다:
   - `https://<사용자ID>.github.io`
   - `http://localhost:8080` (로컬 테스트용)
   - `https://localhost:8080` (로컬 테스트용)

   - 상단 메뉴 **[확장 프로그램] ➔ [Apps Script]**를 클릭합니다.
   - 대시보드의 **[📋 Apps Script 코드 전체 복사]** 버튼을 누르거나 프로젝트 루트의 `BOS_S_Office_Backend_Code.gs` 파일 내용을 그대로 붙여넣고 저장(`Ctrl+S`)합니다.
3. **웹 앱으로 배포 (중요: 액세스 권한 '모든 사용자')**:
   - 우측 상단 **[배포] ➔ [새 배포]** 클릭
   - 유형: **웹 앱 (Web App)** 선택
   - 다음 사용자 권한으로 실행: **'나(bosung3116@gmail.com)'**
   - **액세스할 수 있는 사용자: '모든 사용자 (Anyone)'**  *(★필수: 외부 사용자의 승인 요청을 수신하기 위해 반드시 '모든 사용자'로 설정해야 합니다)*
   - **[배포]** 버튼을 클릭하고 생성된 **웹 앱 URL (`https://script.google.com/macros/s/.../exec`)**을 복사합니다.
4. **BOS'S Office 대시보드에 URL 저장**:
   - BOS'S Office 관리자 대시보드 ➔ **외부 사용자 실시간 승인 연동** 패널의 입력창에 붙여넣고 **[저장]** 및 **[연결 테스트]**를 클릭하면 완료됩니다!
